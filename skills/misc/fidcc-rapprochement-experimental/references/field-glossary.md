# 中文财务术语与字段释义（AI 运行时参考）

用于让 AI 以准确的中文业务语言与用户沟通，并正确映射字段。

| 术语 | 含义 |
|---|---|
| 左表 / 账 | 业务台账（收付款台账、应收/应付明细等） |
| 右表 / 流水 | 银行流水或对方业务系统交易明细 |
| 业务编号（no） | 用于匹配的主键，如流水号、单据号；保留前导零，不做科学计数法转换 |
| 金额（amount） | 一律 `Decimal` 定点；千分位/货币符号/全角先清洗 |
| 借贷方向（direction） | 收/付或借/贷；按 `direction_rule` 归一为带符号金额以同口径比较 |
| 容差（tolerance） | 金额/日期的可接受邻近范围；仅用于差异分级，不放宽自动确认 |
| 勾稽 | 数量与金额的恒等式校验，验证"所有记录都有明确去向" |
| 危险长编号 | 长数字串曾被 Excel 转科学计数法/丢精度；标记并保留原始文本，不自动"修复" |
