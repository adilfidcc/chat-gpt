# 匹配规则与自动确认铁律（AI 运行时参考）

> 面向 AI 与用户的人可读版。权威实现见 `scripts/matcher.py` 与
> [技术设计 §5](../../../docs/design/fcs-reconcile-technical-design-v0.1.md)。

## 分阶段匹配（确定性、唯一性优先；已匹配行不参与后续阶段）

| 阶段 | 条件 | 结果状态 |
|---|---|---|
| 1 | 主键 `no` 两侧均唯一，金额差 = 0 | 已自动匹配 |
| 2 | 复合键（如 `amount+date+counterparty`）两侧唯一且完全一致 | 已自动匹配 |
| 3 | `no` 唯一一致，`0 < 金额差 ≤ 容差` | 疑似匹配（待人工确认） |
| 4 | `no` 唯一一致，`金额差 > 容差` | 金额差异（待处理） |
| 5 | 仅左侧存在 | 左侧单边 |
| 6 | 仅右侧存在 | 右侧单边 |
| 旁路 | `no` 在任一侧多次出现 | 重复编号 / 多候选冲突 |
| 旁路 | 存在数据质量问题 | 数据质量问题 |

## 自动确认铁律（误判率 0，NFR-01）

进入「已自动匹配」当且仅当：**① 候选唯一**（左右各恰一条、无竞争候选）**且 ② 规则完全满足**
（金额差严格 = 0，或复合键逐字段全等）。任一不满足 → 不自动确认，转对应待处理/冲突状态。

## 容差语义（关键）

容差**只做差异分级，不放宽自动确认**：容差内的差异属"不确定"，只提示与分级，交人工判断。
